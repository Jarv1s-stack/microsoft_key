Активация Windows

Выполните команды в PowerShell или командной строке от имени администратора.

1. KMS server
slmgr.vbs -upk

запускает KMS сервера для активаций

2. Установить ключ продукта
slmgr /ipk "W269N-WFGWX-YVC9B-4J6C9-T83GX"

Запускает активацию через серверы Microsoft.

3. Активировать онлайн
slmgr /skms kms.digiboy.ir

подтверждает ключ

4. Проверить активацию
slmgr /ato

Показывает, активирована ли Windows и до какой даты.

5. Keys for Windows
7HNRX-D7KGG-3K4RQ-4WPJ4-YTDFH— Windows 10, 11 Home (Домашняя)
W269N-WFGWX-YVC9B-4J6C9-T83GX — Windows 10, 11 Professional (Профессиональная)
6TP4R-GNPTD-KYYHQ-7B7DP-J447Y — Windows 10, 11 Education

Список ключей для разных версии windows

6. Деактивация ключа Windows
slmgr /upk
slmgr /cpky

Это удалит установленный ключ продукта из текущей Windows.
